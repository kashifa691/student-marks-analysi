# Student Marks Analysis

## About
A beginner Python project that analyzes student marks,
calculates percentages and grades, and identifies the
top-performing student.

## Skills Used
- Python
- Lists and dictionaries
- Loops and functions
- Conditional statements
- Basic statistics

## Features
- Calculates total marks
- Calculates percentage
- Assigns grades
- Identifies pass/fail status
- Calculates class average
- Finds the top-performing student

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run: python STUDENT_ANALYSIS.PY

## Learning Outcome
This project helped me practise Python programming
and basic data analysis.
